# Sprite-Anker v4.3.1

Spawn- und Raid-Sprites werden anhand ihrer sichtbaren Pixel ausgerichtet.

- Transparente Ränder der Gen-5-Sprites beeinflussen die Position nicht mehr.
- Die untere Mitte der sichtbaren Fläche wird auf dem rechten Grasfeld verankert.
- Die sichtbare Pokémonfläche wird auf eine einheitliche Maximalgröße skaliert.
- Name und Seltenheit folgen der gemessenen Position des Pokémon.
- Falls ein Sprite nicht ausgelesen werden kann, greift das bisherige sichere Layout.
